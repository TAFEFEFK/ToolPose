# ToolPose

**ToolPose** is a client-side Fabric mod for 26.2 version that lets you adjust position, rotation, scale, and swing animation of tools and weapons in first-person view.

## Features

- Separate settings for right and left hands
- Per-category profiles (sword, axe, pickaxe, shovel, hoe, food, block, totem, shield, bow, crossbow)
- Adjustable offset, rotation, scale, and swing intensity
- Randomize button for instant fun poses
- Predictable Yaw → Pitch → Roll rotation order
- 11 languages supported
- Open settings with K key
